# Arm C Language Extensions — open specifications

Resource `arm-acle`, version `r2026Q1`, build `1`, package type `material`.

## Distributed scope

Four open ACLE trees: main, Neon, MVE and Morello, including their embedded examples and licensing. The r2026Q1 repository release includes an MVE document still labeled 2021Q4. No Arm hardware, execution, performance, or semantic-conformance qualification.

## Use

The prepared material includes the offline reader, exact source locks, metadata, the SQLite index, and the distributed images or rendered views where applicable. Python 3.11+ with SQLite FTS5 is required; no optional Python package is imported by the reader. The ordinary installation and reader do not fetch material. Run `python3 <prefix>/reader.py --help` to see the resource's existing query interface.

For the C++ and WG14 resources, searches cover their factual indexes only. Their original draft/document bodies are absent. `prepare_external.py` can import a user's existing files or explicitly download selected fixed inputs into a separate directory, checking their original sizes and SHA256 values. Such preparation does not add redistribution permission or make the distributed corpus complete.

## Source master

`materials/` keeps the original distributed upstream files, licenses, authored reader/preparation/verification sources, and factual metadata. `recipe/` keeps the maintenance builder and the same authored tool sources. Generated HTML views and SQLite files remain in the independently downloadable material artifact; `source-master.json` names these outputs and binds the exact artifact. This avoids duplicating generated databases in Git.

The Markdown corpus builder accepts a fresh independent payload directory and an explicitly supplied local Python-Markdown 3.10.2 wheel locked by `recipe/renderer-lock.json` where applicable. That renderer is a preparation dependency, not an installed reader dependency. C++ navigation regeneration requires explicitly prepared source files; WG14 metadata remains the curated selection already supplied. No regeneration or byte-equivalent rebuild is claimed for this publication. Do not overwrite an immutable published identity with different generated bytes.

The official CPG `pack` API generated this artifact from the trusted prepared payload. Upstream files, HTML views, images and SQLite bytes are unchanged. Only neutral naming in authored helpers and the matching payload-inventory hashes changed. Existing CPG MIT text and all upstream license notices remain included. No historical raw execution logs or private filesystem paths are published.
