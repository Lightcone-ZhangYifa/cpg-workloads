CPG worker 011 增量交付说明

基线：compiler-playground 0.21.14。
计划：cpg-resource-research-20261101-v1。
本包是该 worker 的独立增量，不包含完整历史 CPG 工作区，也不替代现有安装器。

1. README 与 CPG-INTEGRATION.zh.md 说明资产范围、固定版本和原 PackageManager 接入。
2. worker-results.jsonl 与 worker-results.csv 为同一组精确任务结果；未知资格保持 null（CSV 中为空）。
3. plan-assignment.jsonl 保存本 worker 的原始任务行。可运行：
   python3 -B tools/validate_worker_results.py --bundle . --assignments plan-assignment.jsonl
4. DELIVERY-MANIFEST.json 覆盖最终交付的全部普通文件，排除它自身。此前的 delivery-selection 仅描述智能体冻结子集；后加整合证据以最终清单为准。
5. 用 unzip 等保留 POSIX 权限的工具解包。最终清单的外部 SHA-256 与 ZIP 的 SHA-256 见三个 worker 的统一交付回执。
   python3 -B tools/verify_delivery.py --bundle . --expected-manifest-sha256 EXTERNAL_MANIFEST_SHA256
6. CPG 集成与最终校验工具使用 hashlib.file_digest，需要 Python >= 3.11；原 reader 的适用 Python 版本见它自己的说明。

已执行的原 CPG 生命周期证据位于 evidence/cpg-lifecycle。日志内的绝对路径记录本次真实执行位置，未被改写为通用路径。
离线材料验证只授予材料/可用性资格，功能为 not_run；没有增加原 1862 项资源的功能或 Dataset 资格。
